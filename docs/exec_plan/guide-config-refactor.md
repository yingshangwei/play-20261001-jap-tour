## 整体完成标准

新增一套攻略只需要新增攻略目录、提供符合 Schema 的配置并注册加载入口。通用组件无需修改；CI 能遍历所有攻略完成配置校验和页面验证；至少两套攻略及两种手账模板通过验收。
