# 共享界面减法

## 范围

按用户要求减少重复、历史过程说明和装饰性板块；仅修改共享渲染与样式，不改配置 1、配置 2 的行程数据，不提交或发布。

## 调整

- 移除首页旧参考复盘六卡及其导航入口；原配置与研究记录保留。
- 压缩首页标题、配置切换和行程概览，去掉装饰圆形、重复介绍与“开始阅读”；手机保留全部主要导航。
- 移除地图每片区的重复 `day-flow` 流程条；保留全天顺序、全天 Google Maps、手机连续分段和每段交通卡。
- 播放器简化为“旅程播放”标题；收起重复跳段列表，展开时暂停。抵达说明仍在详情中，照片署名和节点照片不变。
- 地图 16 家餐厅按日期继续筛选、默认折叠；其中 7 家平价/茶歇候选不是正式餐清单的重复项，全部保留。正式餐比较清单继续展开。
- 烟火资料移入订票区折叠，保留原锚点和全部详情；预订卡仍直接展示日期、票价与限制。
- 动漫候选、行前提醒和来源索引收成折叠；候选注明不自动加入行程。空候选/空来源不显示无内容板块。
- 换宿交箱、寄箱、两端前台要求以及交通待核提示保持直接可见。
